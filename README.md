# HandMouse

Webカメラで手の動きを認識し、マウス操作に使う Windows 向けツールです。

人差し指でカーソルを動かし、親指とのピンチでクリック・右クリック・スクロールできます。

## 必要なもの

- Windows
- Python 3
- Webカメラ

## セットアップ

```powershell
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

初回起動時に、MediaPipe の手検出モデル `hand_landmarker.task` を `models/` へ自動ダウンロードします。

## 実行

```powershell
.\run.bat
```

または:

```powershell
.\venv\Scripts\python.exe main.py
```

カメラ映像のウィンドウが開きます。終了は `q`、`Esc`、`F10`、またはウィンドウを閉じる操作です。

## 操作

| 操作 | やり方 |
|---|---|
| カーソル移動 | 人差し指を動かす |
| 左クリック | 親指 + 人差し指をつまむ |
| 右クリック | 親指 + 薬指をつまむ |
| スクロール | 親指 + 中指をつまんだまま上下に動かす |
| 一時停止 / 再開 | `F8` または `f` |
| キャリブレーション | `c`（約4秒、人差し指で操作したい範囲を動かす） |
| 範囲リセット | `r` |
| 終了 | `q` / `Esc` / `F10` |

ホットキー（`Esc` / `F8` / `F10`）は、カメラウィンドウが前面になくても効きます。

## 調整

うまく動かないときは `main.py` 先頭付近の定数を変えてください。

| 症状 | 定数 | 目安 |
|---|---|---|
| カーソルがガクつく | `ALPHA` | 小さくする（例: `0.25` → `0.15`） |
| クリックが反応しない / しすぎる | `PINCH_RATIO` | 反応しないなら大きく、誤反応なら小さく |
| スクロールが弱い / 強い | `SCROLL_GAIN` | 大きくすると同じ動きで多く進む |

キャリブレーション後の範囲は `calib.json` に保存されます。このファイルは各自の環境用なので、リポジトリには含めていません。

## 注意

このプログラムはマウスを直接動かします。誤操作を減らすため、使わないときは `F8` で一時停止してください。

画面端にカーソルを逃して停止する PyAutoGUI のフェイルセーフは無効にしてあります。止めるときは `Esc` か `F10` を使ってください。
